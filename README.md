# Student Attendance Management System

A simple Student Attendance Management System developed using Python Flask and SQLite.

## Features

- Add Student
- View Students
- Mark Attendance
- Present / Absent Status
- Attendance Report
- SQLite Database

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS

## Project Structure

- app.py
- templates/index.html
- templates/add_student.html
- templates/students.html
- templates/attendance.html
- templates/report.html

## How to Run

Install Flask:

    py -m pip install flask

Run the application:

    py app.py

Open in browser:

    http://127.0.0.1:5000
